## Widget Overview

The Last Modified widget (also used throughout this site) shows you the last modified date of the page. This is valuable for Resource / Knowledge content which sometimes might be dated, without the end user ever knowing when the content was last modified.


With this widget, the end user will always know when the content they’re viewing was last modified to help them make a better informed decision about content integrity.

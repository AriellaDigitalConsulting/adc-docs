## Widget Overview

Make each holiday a memorable one in your LumApps digital workplace with this widget! Simply add any unicode element into the widget settings to change shapes!


## Widget Settings

![](/images/6f08548802fc7446.png)


**Font family**. Input the font family to use for the custom text message which appears in the widget


**Font size**. Define the font size of the custom message


**Unicode Symbol**. Copy and paste any unicode symbol inside of this dialogue box and see the elements change real time to the new symbol. For more symbol choices or ideas, you may click on the hyperlink "these symbols" to see what unicode symbol options exist for your needs.


\*Note: Click on the provided sample URL to find examples of unicode values to put into this field.


![](/images/389561884ea79293.gif)


Adjust the symbol font size to increase it to your liking

Widget Text Field Updates. Updating the widget text is easy! Simple select the “Text” field and either remove the text or update it as needed.


If applicable, you may adjust the symbol color to a different hex value


Finally, you can add shadow values to the symbol. Give it a try!

## Widget Overview

The Estimated Reading Time widget automatically calculates and displays the estimated time required to read a page based on the total word count of the page content. It dynamically updates the on-page reading time based on content changes and requires no manual configuration, making it suitable for use across Knowledge Base articles, news pages, resource libraries, and documentation to provide users with a consistent and accurate reading-time indicator.

## Widget Interface

The widget interface is a responsive design developed with LumApps Designer best practices in mind, so it adapts nicely on desktop and mobile.

![](/images/b339e3a0016033c4.png)

Key widget features and customizations for page administrators

1.  Default page reader estimate is based on 240 words-per-minute
2.  Custom-select the widgets to use for word count
3.  Multi-language support
4.  Customize the “Estimated reading time” label for both single entry and multiple entries
5.  Configure the desired words per minute

## Widget Settings


![](/images/5ae88b26a35919dd.png)

-   Show help icon: Enable the help icon which tells the user (a) how many words are on the page, (b) which widgets are used in the calculation and (c) initial content on the page.
-   Customize label. The default label in the widget is “Estimated reading time”. By checking off the tick box, the user will now be able to customize the label.
-   Customize label active. When the tick box is activate, the user will have two fields to customize:
    -   Singular form (1 minute) - this is when the text is only one minute
    -   Plural form (this is when text is over 1 minute)



![](/images/99a1b09d615ca234.png)

-   Widget types to include: Type in the widgets which you’d like to include in the calculation. The default widgets are HTML, TITLE, INTRO, and RICH TEXT (CONTRIBUTION)).

![](/images/5b0f58b961c0480a.png)The widget settings shows by default which widgets are on the page

![](/images/5b0f58b961c0480a.png)

-   Words per minute: Page admins can determine the exact calculation for the words per minute, based on how well they know the users consuming their content.

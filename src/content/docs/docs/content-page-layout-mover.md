### Widget Overview

This is your Content Page Layout Mover widget, designed to streamline the process of copying page layouts within a single site, or across multiple sites within a single LumApps platform. This includes copying widgets, their styling, headers, and all widget types, including Rich Text widgets. This widget is ideal for situations like preparing major upgrades for a Content while still applying minor design updates to a “live” version.

### Widget Interface

![](/images/671a19719ca8d9da.png)

This widget interface is user-friendly and follows LumApps Designer best practices. It includes the following steps:

1.  **Select the Source Site**: Choose the site containing the Content you want to copy.
2.  **Select the Source Content**: Identify the Content you want to copy.
3.  **Select the Destination Site**: Choose the site where you want the copied Content to be placed.
4.  **Select the Destination Content**: Specify the Content where the copied information should go.

### Key Features:

• The widget considers the identity of the requestor and limits the selection of source and destination sites to only those where the requestor has the necessary permissions. This ensures secure and authorized usage of the widget. \*NOTE: Only a Site Administrator or above can access this widget.

• A pre-action message will appear to confirm the details of the operation (source and destination Content) to avoid confusion.

• Click the “Move” button to trigger the copy action.

• A post-action message will confirm that the Content has been successfully copied.


### Widget Settings

This widget does not require any specific configuration or installation, ensuring a hassle-free setup.


### Added Value

This widget provides the following benefits:

-   Enables LumApps customers to manage major upgrades for a Content while maintaining minor updates for a “live” version.
-   Simplifies the process of content duplication, saving time and effort.
-   Ensures accuracy and consistency by copying all widgets, styles, and headers.
-   Respects user permissions by limiting access to appropriate sites, ensuring secure content management.
-   Improves workflow efficiency with a seamless and responsive interface.

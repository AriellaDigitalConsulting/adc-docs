## Widget Overview

This is your Media mover widget where you can search for any media file from your site, and move it to a different folder or subfolder!



![](/images/85155ca95fdace97.png)

## Widget Interface

Search for the source media which you would like to move



Search for the destination media folder into which you’d like to move the media file into



Click “Move”



You will see a success message informing you that the media file has successfully moved to a new folder!

![](/images/04820325181e8c3a.png)



\*NOTE: Once a media file is moved to a different location, you must refresh your screen to see the new location of the media file in the widget

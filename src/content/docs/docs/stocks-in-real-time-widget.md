## Widget Overview

The Stocks in Real TIme widget displays the stock price in realtime, without the user needing to make any form of updates or any page refresh.



![](/images/897a7b095567e268.gif)



WIth this widget, the LumApps homepage (or any page this widget is on) will have a dynamic instead of a static look for your users

## Widget Interface

The widget displays the stock ticker, stock name, stock value.



Toggle last updated. The user has the ability to toggle on / off the last updated date

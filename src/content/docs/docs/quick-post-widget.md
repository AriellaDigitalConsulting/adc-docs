## Widget Overview

The Quick Contribution widget allows the user to make a post in any **Space or Community** with just one click


Widget Use Case:

One-click action without leaving the current page. Today, LumApps has a “CREATE” CTA in the global navigation where a user can create a Post or Content. However, it takes multiple clicks for a user to find the community where they want to post to, with the LumApps’ OOTB CTA. With the Quick Post widget, an admin can preconfigure the CTA to post into any specific Space or Community directly from a homepage or a landing page, instead of leaving the page to post in the Space or Community, savings users multiple clicks and waits during loading time.

## Widget Settings

Set Call to Action label. Define the copy text to display inside of the CTA


Define the background colors of this CTA to fit within the brand guidelines of your organization.


-   Neutral state color of the background
-   Hover state color of the background



Select Space or Community. Search for the Space or Community you would like to map this widget to

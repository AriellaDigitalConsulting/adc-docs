## Widget Overview

Community managers and moderators can see how many community post questions remain unanswered; i.e., not marked as Relevent, when adding this widget to their page.

![](/images/f34a70c898145bcd.png)

##
Widget Settings

Two main options exist in the settings of this widget


Select community. Select one or multiple community from which to show how many unanswered (i.e., not marked as Relevant) questions there are.


\*NOTE: Leaving this field blank shows a value from every community on the site


Display posts from communities you follow.


![](/images/b917f266df15225c.png)

## Added Value

With this widget, if used right you will see added value to your digital workplace operations such as:

-   Improve community engaged
-   Increase response time to a post
-   See in real time how many questions still remain unanswered



Use this widget on either a community homepage, or on a stand alone page to see in real time when a question has been asked or answered.

## Widget Overview

The Metadata Edit and Lookup widget allows the site administrators to quickly and easily find the metadata they are looking for and to update its name




![](/images/f5eadbe949c04e0a.gif)



## Widget Interface

Select whether you’d like to search for Platform metadata, Site metadata, or Both (Both is the selected default)



Enter the metadata you’re looking for in search and select the desired metadata value



Enter the new name for the metadata and Save



The metadata name has been updated!



NOTE: After the metadata has been updated, you must refresh the page you’re on to see the changes take place

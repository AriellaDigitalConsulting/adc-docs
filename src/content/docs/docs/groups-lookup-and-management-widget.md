## Widget Overview

This widget allows you to search for groups and add/update users without having to go into the back office to do it manually

![](/images/956ddc5587c0c0d1.png)

##
Widget Interface

Select whether you’d like to search for Platform Groups or the groups from the current site (Current Site is the default select state)


Enter the group name you’re looking for in search and select the desired metadata value


![](/images/98463e186687983d.png)


There are two entry fields: (1) Enter a comma separated list of user emails to add to this group, and (2) Enter a comma separated list of user emails to remove from this group


![](/images/6bfed2018ad5e84a.png)


You will see all the users in this group below


![](/images/3fe305987971a620.png)


Add and/or remove users into the field, click the “ADD/REMOVE USERS” CTA and the users will be automatically added.


NOTE: After the user list has been updated, you must refresh the page you’re on to see the changes take place


## Widget Settings

With this widget, you can also display the Group ID, which makes it a lot simpler to troubleshoot and provide any technical information to LumApps technical support, or to obtain a Feed ID for any [LumApps Toolbox](https://lumapps-apiclient.appspot.com/doc/index.html) imports/exports


![](/images/1d1f1ae8a90647ff.png)

##
Added Value

When used right this widget will add quite a bit of value to the project core and administrative team such as:

-   Save valuable admin and core team time
-   Easily search for any group on your site
-   Manage the group by adding/removing users (for LumApps groups only)
-   Single click functions reduce long waits and loading times

## Widget Overview

The Follow Interest widget enhances the native LumApps "follow interest" functionality. While LumApps normally allows users to follow an interest—defined as a Custom Content Type combined with optional metadata (using an OR condition)—it restricts pages to only one "follow interest" button.

This widget overcomes that limitation by enabling multiple "follow interest" buttons on the same page. It ensures a smoother and more flexible experience for users who want to follow various interests at once.

Additionally, this widget resolves a common issue in recent LumApps versions where the standard "follow interest" button appears clickable even when the interest is already followed, creating confusion. Our widget delivers a cleaner user experience by properly reflecting the followed/unfollowed state.

## Widget Interface

The widget interface is a responsive design developed with LumApps Designer best practices in mind.

-   Each button corresponds to a specific interest (a combination of Custom Content Type and metadata).
-   Buttons visually indicate whether the user is currently following the interest.
-   When clicked, the interest is followed or unfollowed in real-time.
-   Once an interest is followed, the button state updates to reflect the change, eliminating redundant interactions.

## Widget Settings

-   Configure each button with a specific Custom Content Type and optional metadata.
-   Position multiple buttons anywhere within the same page layout.
-   Styling options can be adjusted through LumApps Designer settings to match your site theme.

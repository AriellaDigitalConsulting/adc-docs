## Widget Overview


Display a manual or dynamic selection of community posts from one or several communities.


The Community posts in real-time widget is an enhancement to LumApps' OOTB Community posts list widget, exposing additional UI parameters as well as displays new posts almost instantaneously upon creation, without any need for a page refresh!


This widget may be added to either your site's Homepage, to a team or to a community homepage, or to any other landing page


\*NOTE: This widget is not meant to be a replacement to LumApps' OOTB Community post list widget, but rather a supplement. Note that this widget can not be mapped to a LumApps Content Filter widget due to LumApps limitations

##
Widget Settings

![](/images/59a7e276edb3145e.png)

There are two types of source selections on the widget. You can either select a community or multiple communities from the Select the communities dropdown, or you can choose the "Display posts from communities you follow" option, which displays it dynamically based on the user's Followed communities.


**NOTE**: Leaving the "Select the communities" section blank will display all communities


## Filter and Sort

You can filter on any of the four post types defined by LumApps. Additionally, post list contents can also be sorted by Publication or Modification date in ascending or descending order


## Detail level selection

This section outlines the metadata and other parameters that can be toggled on or off within the widget.


1\. Display reading buttons (Mark as read). The use case here is for the user to select whether they have read the message or not. For example, if a user is managing a support community they may want to keep track of which community posts they have already read or not, and this gives them that option. When a post is greyed out, it means the users has read it

![](/images/6ddb188a2a010e67.png)


2\. Display the post content simply displays the content within the widget. If toggled off the contents will not display


**3\. Display publication date** displays when the post was published


**4\. Display the last modified date** displays when the post was last modified.


\*NOTE: This feature is unique to this widget only.


5\. Display the author. The author display can be toggled on or off with this setting.

##
Behavior


Finally, there are multiple options in the behavior section.


How many posts should we display. The page admin can define how many community posts they wish to display within the widget.


How many characters should we display? Define how many characters of the message content to display in a community post


Message when no results are available. They can also customize the empty widget message, when no posts display within the widget


This widget should be the main widget. This is a more advanced option, when this widget is mapped to the proprietary Search widget created by ADC


![](/images/6562c165a2ac5814.png)


Ungrouped layout. Show the community posts in the ungrouped mode.


**Comments**. Show widget comments

**Use Cases**

-   **Real-Time Q&A during corporate town halls**. Use this widget on a town hall live stream page to see new posts / comments appear in real time.
-   Communities with high volumes of posts and discussions.
-   Instant team room conversations & responses for end-user support.

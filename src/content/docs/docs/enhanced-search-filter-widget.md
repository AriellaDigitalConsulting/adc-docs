## Widget Overview

The Enhanced Search Filter widget is an improvement to the LumApps’ OOTB Content Filter widget. This widget uses NL technology and interpretation to search queries and present the search results to the user in real time



This first version of the widget can only search queries when it’s mapped to ADC’s Search Community Posts in Real Time widget



![](/images/f3c6ce011a05ac5e.gif)



## Widget Settings

The widget allows you to also toggle and filter on different community posts if that option is selected

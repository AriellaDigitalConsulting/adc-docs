## Widget Overview

The Follow People widget by ADC enhances the native LumApps "follow user" functionality. While LumApps normally allows users to follow others only by clicking on their profile in order to follow, this widget overcomes that limitation by allowing you, the admin, to put a “Follow CXO” CTA on any page, including a homepage. This ensures a smoother and more flexible experience for users who want to follow leaders, and allows them to see content created by those leaders (or on their behalf) from the LumApps Personal Feed (read more about the [Personal Feed here](https://docs.lumapps.com/docs/design-l6453148049650844)).

## Widget Interface

The widget interface is a responsive design developed with LumApps Designer best practices in mind.

-   Each button corresponds to a specific LumApps user
-   Buttons visually indicate whether the user is currently being followed or not.
-   When clicked, the user is followed or unfollowed in real-time.
-   Once a user is followed, the button state updates to reflect the change, eliminating redundant interactions.

## Widget Settings

-   Configure each button to follow a specific user.
-   Position multiple buttons anywhere within the same page layout.
-   Styling options can be adjusted through LumApps Designer settings to match your site theme.
-   Add a custom label; i.e., Follow CXO

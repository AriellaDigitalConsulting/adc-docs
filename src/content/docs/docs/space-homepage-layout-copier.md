### Widget Overview

The **Space Homepage Layout Copier** widget allows users to copy the dashboard of one space to another. Spaces can consist of various sections, including a dashboard, lists of articles, places, calendars, and more. This widget specifically focuses on cloning the dashboard configuration from one space to another.

### Widget Interface

The widget is available to Site administrators only

![](/images/3839e2d1c20c6935.png)

If the user is a site administrator for at least one site, he will be presented with this interface:

![](/images/7e072b8c03959d6c.png)

1\. Select Source Space:

Choose the space that contains the dashboard you want to clone.

2\. Select Destination Space:

Choose the space where you want the dashboard to be cloned.

3\. Clone Action:

Click the “Clone” button to replicate the dashboard from the source space to the destination space.

4\. Access Control:

• If the user does not have modification rights for a site, they will not be able to clone any space from or to that site.

• If the user is not a site administrator or platform administrator, the widget will not display any spaces or sites for selection.

#### Note:

• If the dashboard display attribute was not previously enabled in the destination space, the widget does not force it to be enabled. The user must manage such settings manually.

A confirmation dialog is proposed to the end users before the action is taken.

![](/images/90d76fbee8572b4d.png)

### Added Value

The Space Dashboard Layout Cloner widget streamlines the process of replicating dashboard configurations across spaces, saving time and ensuring consistency in layouts and configurations across different spaces in a site.

## Widget Overview

The Back to Top widget can be added to any page or community, and provides a quick way for the user to get back to the top of the page

![](/images/774788018bb08137.gif)

## Widget Settings

The widget allows a lot of customization to match the branding needs of your organization.


Message to display to the end user. This is a default generic message that can display in a widget letting the user know how to interact with the widget.


Symbol for the up arrow. This can be modified to any other unicode symbol


Message for the top button. The page admin can customize the message inside the button.


Neutral state background color. The widget offers capability to modify all of the button states. As implied by the title, this allows the page admin to modify the neutral state background color


Hover state background color. Define button hover state


Label color. Define the color of the font inside the button

![](/images/1ad64b4c1302c325.png)

Stick to the bottom of the page. This option is useful when adding this button to a community, so that it doesn’t overlap with the community contribution experience.

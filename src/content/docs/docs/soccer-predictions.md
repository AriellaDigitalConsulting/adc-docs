## Widget Overview

Soccer Predictions is a match prediction game for employees. This extension is built to enable employee match prediction functionality natively within the LumApps Employee Experience Platform: employees predict the result of each match, score points for their predictions, and compare their score with colleagues on a leaderboard. The widget is embedded directly into LumApps pages or Spaces via the platform's native extension framework, requiring no external application dependencies or third-party redirects.

## Use cases

Use Soccer Predictions when you want a game or gamification element on your employee experience platform, for example:

- **Employee engagement during big tournaments:** run a prediction contest for a competition such as the FIFA World Cup.
- **Friendly competition:** the leaderboard and personal score turn predictions into a company-wide game.
- **Community building:** give employees across teams and offices a shared event to follow and talk about.

## Widget Settings

**Define the title of the 'Pronostics' tab**. This customizes the widget heading label

**Define the title of the 'Leaders' tab**. Customize the leaderboard tab label.

**Select a Competition.** Choose the Soccer competition for the widget before saving it to the page (i.e., FIFA World Cup). Once the competition is selected, and at least one match has been submitted, the page admin will no longer be able to update this selection

## Installation Instructions

Follow LumApps instructions to add the widget from the Extension library

Then, if you wish to activate the leaderboard, you must input the proxy service URL. Please contact ADC to activate the Leaderboard.

\*NOTE: In addition to collecting all the information mentioned in the Information Collected By Our Extension Widgets section of our [TOS](/docs/terms-of-use), this widget also collects the User ID (uid string) in order to present a leaderboard.

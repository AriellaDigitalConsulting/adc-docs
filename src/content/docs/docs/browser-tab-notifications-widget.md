## Widget Overview

The Browser Tab Notifications widget displays a badge in the user’s browser tab when a new community post or a new unanswered question is created in a community which has this widget added. The counter will increase each time a new post has been created, and once a question of the post has been answered, or if the post was deleted, the counter will decrease.


\*NOTE: This widget can also be added to any page, not only a community.


## Widget Interface

Custom message. The page admin can add a custom message inside the widget.

![](/images/252fcb51a924585d.png)

Toggle audio notification. The user has the ability to toggle audio notifications on or off. The the audio is toggled off, the user will no longer receive any audio notifications from this page unless they turn them back on.

![](/images/da04e80c47077335.png)

##
Widget Settings

![](/images/02fef16284db5b05.png)


Select the communities. Choose which community(ies) you would like to map to this widget’s notification settings. Once a community is selected, any time a new post is created from that community, the user will get a notification from the browser tab which this widget is added to


NOTE:

-   Leaving the "Select the communities" section blank will display posts from all communities
-   The browser tab of the desired page / community with this widget must be open in order to receive notifications.



![](/images/639fb540c7b15a91.png)


Available sounds. When this option is toggled on, the user will get an audio notification each time a new post is created.


**\*NOTE**: The browser tab of the desired page / community with this widget must be open in order to receive the audio notifications.


The page admin can set an audio from the preloaded audio options


![](/images/b68a24e085b58864.png)

Toggle browser tab badge. This option enables the browser tab badge setting. Once enabled the user will see a badge with a counter in the browser tab, when a new community post is created in the community which this widget is added. The counter will increase with the creat of each new post, and will decrease if a post is deleted or if an unanswered question has been answered / marked as relevant.

![](/images/df5d88e6216f3267.png)

Toggle notification bar badge. This option toggles an indicator on the page, to show the user how many new community posts have been created from the community this widget is mapped to, since the last time the user loaded the page.


The indicator on the page will change in real time when a new community post is created and is displayed from the page(s) and/or community(ies) that this indicator is displayed on.


See below:

![](/images/93306046f22948c0.gif)


\*Integration Use Case: This is a cache-based integration showing how much new content appeared on the page the user is on, since the last time they’ve loaded the page. This is useful for users who have to track large volumes of posts and know how many new posts they’ve missed since they left their desk or their active browser tab to be able to catch up.

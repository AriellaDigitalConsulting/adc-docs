## Widget Overview

The Bunchball Leaderboard widget allows you to display one or multiple leaderboards based on one or multiple Group Classes


\*NOTE: This widget requires the customer to have Nitro Studio Bunchball as a gamification solution powered by [BI Worldwide](https://www.biworldwide.com/gamification/bunchball-nitro/)

##
Widget Interface

The widget interface is a responsive design developed with LumApps Designer best practices in mind, When the widget is assigned to display contents from multiple leaderboards, the leaderboards will display in a tabulated view as shown in the screenshot below


The points displayed are based on specific user actions in LumApps which users get rewarded for based on Missions they complete.


\***NOTE**: All Missions are assigned in Nitro Studio’s back office interface


![](/images/5e869518aace82f8.png)

### Color Settings

You also have the ability to customize the widget to display primary and secondary colors based on your company’s brand identity


Widget primary color. Define the primary color of the widget. This is reflected in the user name, hover state, and the pagination circle


Widget secondary color. The secondary color is impacted in the leaderboard tabs neutral state, user Level (above username) and user points

Widget gradient light. The gradient light and dark impacts the widget header beneath the title, so that the user can have a gradient as an option in the widget header

Widget gradient dark. See above

Widget font family. Select from a pre-existing list of fonts for your widget. CSS may also be used to overwrite and add new fonts
